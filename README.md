## ✨ Key Features & Highlights

- **⚡ Lightning-Fast Edge Architecture:** Sub-second page loads powered by Vercel Serverless Edge and Next.js 14 SSG/SSR.
- **📱 100% Mobile & Device Responsive:** Handcrafted CSS grid/flex layouts with zero horizontal scroll leakage across all smartphone viewports.
- **💬 Direct Enquiry-to-WhatsApp Flow:** Real-time form submissions validated with Zod, persisted into Supabase PostgreSQL, and piped directly into WhatsApp with auto-generated reference IDs (`VV-2026-0001`).
- **🗄️ Supabase PostgreSQL + RLS:** Cloud database architecture with Row Level Security protecting client data and automated sequential ID sequences.
- **🛡️ Secure Admin Portal (`/admin`):** Passwordless cookie-authenticated operations dashboard with real-time analytics, status toggles (`new` ➔ `in-progress` ➔ `completed`), client search, and live database latency ping tools.
- **🎨 Glassmorphic Dark Aesthetics:** Bespoke Midnight (`#080B1C`) visual language accented with electric cyan, purple glow, and royal gold gradients.
- **🔍 SEO & Meta Engine:** Automated JSON-LD structured data, dynamic `sitemap.xml`, `robots.txt`, and OpenGraph social share cards.

```text
            [ Vercel Edge Network ]
                       │
       ┌───────────────┴───────────────┐

```

## ⚡ Quick Start Guide

### Prerequisites
- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### 1. Clone & Install
```bash
git clone https://github.com/KadariUday/visionverse24.git
cd visionverse24
npm install --legacy-peer-deps
```

### 2. Configure Environment
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_OWNER_WHATSAPP_NUMBER=919392438853
NEXT_PUBLIC_OWNER_EMAIL=kadariudaycl@gmail.com
NEXT_PUBLIC_OWNER_PHONE=+91-9392438853

# Supabase PostgreSQL
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key

# Admin Portal Authentication
ADMIN_SECRET_KEY=visionverse24-admin-dev-key
ADMIN_EMAIL=kadariudaycl@gmail.com
```

### 3. Verify Database & Start Server
```bash
# Test Supabase connection:
npm run check-db

# Start development server:
npm run dev
```

Visit **[http://localhost:3000](http://localhost:3000)** in your browser!

## 🗄️ Supabase Database Setup

1. Open your project on **[Supabase](https://supabase.com)**.
2. In the left navigation, click **SQL Editor** (`>_`).
3. Copy the entire contents of [`supabase/migrations/001_initial_schema.sql`](supabase/migrations/001_initial_schema.sql) and click **Run**.
4. The script automatically sets up:
   - `enquiries` table with constraints and RLS security policies.
   - Sequential ID sequence (`VV-YYYY-XXXX`).
   - `projects` and `services` tables.
   - Automatic `updated_at` triggers.
5. In your terminal, run `npm run check-db` to verify the connection turns green!
